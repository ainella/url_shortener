# ShortyURL

This is a URL shortener service. It is built with React and Vite.

[Frontend Demo](shortyurl.ainella.com)

![Demo](https://i.imgur.com/cFDJqL8.png)

![Demo2](https://i.imgur.com/L2y5ebT.png)

## Tech Stack

* **Framework:** React 18
* **Build Tool:** Vite
* **Backend:** FastApi
* **Database:** PostgreSQL

## Installation & Setup

### Prerequisites

Before you begin, ensure you have the following installed on your machine:

* [Node.js](https://nodejs.org/) (v16 or higher recommended)
* [Backend](https://gitlab.com/ainella/url-shortener/backend) set up

### Installation

* Make a copy of the .env.example file to create your own .env file:

```shell
cp .env.example .env
```

* Install packages for Node.js

```shell
npm install
```

## Running

```shell
npm run dev    
```
