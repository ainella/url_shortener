# ShortyURL - Frontend

This is the frontend user interface for the ShortyURL Shortener application. It is built with React and Vite, providing a fast, responsive, and user-friendly way to create, manage, and track shortened links.

## Features

* **Shorten URLs:** Convert long, messy web addresses into clean, clickable short links.
* **Custom Display Names:** Assign human-readable titles (e.g., "My Vacation Video") to your links so you know exactly what they are.
* **Link Dashboard:** A dedicated "My Links" page to view your complete history of shortened URLs fetched directly from the database.
* **Full CRUD Capabilities:** Edit display names on the fly or delete links you no longer need.
* **Seamless Navigation:** Uses React Router for instant, page-refresh-free navigation.

## Tech Stack

* **Framework:** React 18
* **Build Tool:** Vite
* **Routing:** React Router v6
* **Icons:** React Icons (FontAwesome)
* **Styling:** Custom Vanilla CSS

## Prerequisites

Before you begin, ensure you have the following installed on your machine:
* [Node.js](https://nodejs.org/) (v16 or higher recommended)
* A package manager like `npm` (comes with Node.js)
